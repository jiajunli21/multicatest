# IA-004: 指南内容接口

## 接口概览

| 属性 | 值 |
|------|-----|
| 方法 | `GET` |
| 路径 | `/api/v1/morning-report/guide` |
| 处理方式 | 新增/复用运营配置读取 |
| 权限 | [default] 无需登录 |
| Mock | 是 [mock] |

## 请求参数

无请求参数。

## 返回数据

### 字段说明

| 字段路径 | 类型 | 说明 | 状态 |
|-----------|------|------|------|
| `guide` | object | 指南内容对象 | — |
| `guide.content` | string | Markdown 格式的指南内容 | [mock] |
| `guide.update_time` | string | 内容更新时间 (ISO-8601) | [verified] |

### 权限兜底

无需登录，无权限校验。

### 空数据规则

配置缺失或内容为空时：
- `guide.content` 返回空字符串 `""`

### 错误/降级规则

| 场景 | HTTP 状态码 | code | 说明 |
|------|-------------|------|------|
| 运营配置不可用 | 200 | — | 返回空 content；Phase 1 Mock 不受影响 |
| 服务异常 | 500 | `INTERNAL_ERROR` | — |

## 示例请求

```bash
curl -X GET "https://api.example.com/api/v1/morning-report/guide"
```

## 示例响应

### 正常响应

```json
{
  "guide": {
    "content": "# [mock] 早盘宝使用指南\n\n## 什么是早盘宝？\n\n早盘宝是基于 ETF 多因子评分模型...\n\n## 评分模型\n\n早盘宝采用四因子加权评分模型：\n\n| 因子 | 权重 | 说明 |\n|------|------|------|\n| 热度因子 | 50% | 基于搜索热度和首购热度 |\n| 动量因子 | 35% | 基于近期价格动量 |\n| 流动性因子 | 10% | 基于成交额 |\n| 低波因子 | 5% | 基于波动率（取反） |\n\n## 使用建议\n\n- 早盘宝信号仅供投资参考，不构成投资建议\n- 请结合自身风险偏好和投资目标独立决策\n- 市场有风险，投资需谨慎\n",
    "update_time": "2026-05-25T08:00:00+08:00"
  }

```

### 空配置响应

```json
{
  "guide": {
    "content": "",
    "update_time": "2026-05-25T08:00:00+08:00"
  }
}
```

## 兼容性说明

- 新增接口，无兼容性问题
- `content` 为 Markdown 格式，前端可用 Markdown 渲染器展示
- Phase 2 从运营配置读取真实内容，字段结构不变
